## TEST QUIZ

Test Quiz is a full-stack MERN application and end-to-end testing using Cypress where users are presented with 10 
random questions and shows a final score at the end. This is a great tool to test your knowledge on coding fundamentals 
and improve your skills!

## Installation
1. Git clone the repository
    > git clone <github.repo.url>
2. Install dependencies
    > npm run install
3. Seed the database (make sure MongoDB is running locally)
    > npx tsc
    > node dist/seeds/seed.js
4. Start the application
    > npm run server:dev (Develop/server)
    > npm run client:dev (Develop/client)
5. Testing with Cypress
    > npx cypress open (Develop)



## Technologies Used
* MongoDB
* Express.js for Backend API
* React + Vite for Frontend
* Node.js
* Typescript for frontend and backend
* Cypress for Testing Framework
